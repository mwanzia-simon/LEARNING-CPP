# C++ Learning Journey 

Welcome to my C++ learning repository!

I'm using this repository to document my journey as I learn **C++**, mainly focusing on programming fundamentals and **Object-Oriented Programming (OOP)**.

The goal is to learn by writing code, experimenting with concepts, building small programs, and documenting my progress along the way.

##  What I'm Learning

* Variables and data types
* Input and output
* Operators
* Conditional statements
* Loops
* Functions
* Arrays
* Strings
* Pointers
* References
* Structures

### Object-Oriented Programming

* Classes and objects
* Constructors and destructors
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Access modifiers
* Composition

### Later Topics

* Standard Template Library (STL)
* Vectors
* Maps
* Sets
* Algorithms
* Exception handling
* File handling
* Templates
* Memory management
* Data structures and algorithms
