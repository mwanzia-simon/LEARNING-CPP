# C++ File Handling

This directory contains my practical exercises and implementations as I learn file handling in C++.

![file handling banner](../docs/file_handling_banner.jpg)

## Topics Covered

- Introduction to file handling
- Writing to files using `ofstream`
- Reading files using `ifstream`
- Reading and writing using `fstream`
- File opening modes
- Appending data to existing files
- Checking whether files open successfully
- Basic file handling applications

To understand how C++ programs interact with external files to store, retrieve, and manage persistent data.
